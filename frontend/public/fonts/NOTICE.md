# Typeface notices

The webfonts in this directory are self-hosted subsets of the following open-source families:

- [DM Sans](https://github.com/googlefonts/dm-fonts)
- [IBM Plex Mono](https://github.com/IBM/plex)
- [Instrument Serif](https://github.com/Instrument/instrument-serif)
- [Manrope](https://github.com/sharanda/manrope)

Each family is distributed under the SIL Open Font License 1.1. The font files are served locally to remove render-blocking third-party requests and keep the interface available without external font hosts.
